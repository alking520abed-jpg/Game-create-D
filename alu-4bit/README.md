تصميم وحدة حساب ومنطق (ALU) توافقية بأربع بتات، على مستوى البوابات وقطع 74xx، جاهز للرسم في Multisim.

> **ملاحظة:** هذا المجلد يحتوي وثيقة التصميم وسكربت التحقق فقط. ملف Multisim (`.ms14`) غير موجود هنا ويجب رسمه داخل البرنامج باتباع التوصيلات أدناه.

## التحقق

`alu_verify.py` يحاكي الدائرة بوابةً ببوابة (بما فيها تحويل BCD) ويقارنها بالمطلوب لكل الحالات الـ 2048:

## المداخل والمخارج

- المداخل: `A[3:0]`، `B[3:0]`، `M`، `S1`، `S0`
- المخارج: `L[3:0]` (4 LEDs)، `R[4:0]` (شاشتا 7-segment، عشري 00–31)، `N` (LED)

| M | S1 | S0 | العملية |
|---|---|---|---|
| 0 | 0 | 0 | A AND B |
| 0 | 0 | 1 | A XOR B |
| 0 | 1 | 0 | A NAND B |
| 0 | 1 | 1 | A XNOR B |
| 1 | 0 | 0 | A + B |
| 1 | 0 | 1 | A − B (يعرض \|A−B\|، و N=1 إذا A<B) |
| 1 | 1 | 0 | A + B + 1 |
| 1 | 1 | 1 | 2A |

في الوضع المنطقي R = 0 و N = 0، وفي الوضع الحسابي L = 0.

## 1) الوحدة المنطقية (L)

لكل بت i من 0 إلى 3:

- `AND_i = A_i · B_i` (7408)
- `XOR_i = A_i ⊕ B_i` (7486)
- `NAND_i = (A_i · B_i)'` (7400)
- `XNOR_i = NOT(XOR_i)` (7404)

كل نصف من 74153 يخدم بتاً واحداً:

- `C0 = AND_i`، `C1 = XOR_i`، `C2 = NAND_i`، `C3 = XNOR_i`
- مدخلا الاختيار: `B = S1`، `A = S0`
- طرفا الـ Strobe (`~1G` و `~2G`) يوصلان بـ `M` مباشرة، فيصبح L = 0 عند M = 1
- المخرج Y إلى LED البت `L_i`

## 2) إشارات التحكم

- `nS1 = NOT S1`
- `D = nS1 · S0` (إشارة الطرح)
- `E = S1 · S0` (إشارة 2A)
- `Cin = S1 ⊕ S0`
- `nD = D ⊕ 1` (بوابة XOR فائضة، أحد مدخليها على VCC)

## 3) الوحدة الحسابية (R و N)

1. عكس B عند الطرح: `BX_i = B_i ⊕ D`
2. 74157: Select = `E`، مداخل A = `BX_i`، مداخل B = `A_i`، و `~G` على الأرضي. المخرج `Y_i`
3. الجامع الأول (74283): A = `A3..A0`، B = `Y3..Y0`، C0 = `Cin`. المخارج `S3..S0` و `C4`

   | S1 S0 | Y | Cin | الناتج |
   |---|---|---|---|
   | 00 | B | 0 | A+B |
   | 01 | B' | 1 | A−B |
   | 10 | B | 1 | A+B+1 |
   | 11 | A | 0 | 2A |

4. الإشارة السالبة: `N = M · D · C4'` (7411). في الطرح C4 = 0 تعني A < B
5. القيمة المطلقة: `T_i = S_i ⊕ N`، ثم الجامع الثاني (74283): A = `T3..T0`، B = `0000`، C0 = `N`. المخارج `Z3..Z0` (يُهمل C4)
6. المخرج النهائي:
   - `R_i = M · Z_i` للبتات 0 إلى 3 (7408)
   - `R4 = M · C4 · nD` (7411)

## 4) التحويل إلى عشري (00–31)

المرحلة الأولى:

- `G1 = R4 · (R3 + R2)`
- جامع ثالث: A = `(0, R4, R3, R2)`، B = `(0, 0, G1, G1)`، C0 = 0. المخارج `P3..P0`

المرحلة الثانية:

- `X = (P2, P1, P0, R1)` بحيث X3 = P2 و X0 = R1
- `G2 = X3 + X2 · (X1 + X0)`
- جامع رابع: A = `X`، B = `(0, 0, G2, G2)`، C0 = 0. المخارج `Q3..Q0`

الخانات:

- الآحاد إلى 7447 الأول: `D = Q2`، `C = Q1`، `B = Q0`، `A = R0`
- العشرات إلى 7447 الثاني: `D = 0`، `C = 0`، `B = P3`، `A = Q3`

في كل 7447: `~LT` و `~RBI` و `~BI/RBO` على VCC، والمخارج a..g عبر مقاومات 220Ω إلى شاشة Common Anode طرفها المشترك على VCC.

## ملاحظات عند الرسم في Multisim

- في 74283 و 7447 الطرف A هو الأقل وزناً (LSB).
- في 74153 مدخل الاختيار B هو الأعلى وزناً (S1) و A هو الأدنى (S0).
- استخدم Net Labels بدل الأسلاك الطويلة، وقسّم الدائرة إلى Subcircuits: Logic و Arithmetic و BCD و Display.
