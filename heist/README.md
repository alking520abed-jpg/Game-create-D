# الخزنة

لعبة سطو مسلّح من منظور الشخص الأول للأندرويد (Godot 4.5) — ستة فصول: الدخول، غرفة التحكم، الخزنة، الذهب، الحصار، الهروب.
قصة وشخصيات أصلية مستوحاة من أجواء مسلسلات السطو.

- الشخصيات: بشر واقعيون مولَّدون من بيانات MakeHuman (CC0) عبر `tools/chargen/`.
- الحركات: Quaternius Universal Animation Library 1 و 2 (CC0).
- الأسلحة: Quaternius Ultimate Gun Pack (CC0). الخامات: ambientCG (CC0). الأصوات مولّدة بـ `tools/assetgen/sounds.py`.
- الخط: Cairo (OFL).

ملف APK يُبنى تلقائياً عبر GitHub Actions (تبويب Actions ← «Build Heist APK» ← `alkhazna-apk`).

**تنبيه:** هذه النسخة لم تُختبر باللعب بعد — الكود يُترجم بلا أخطاء لكن لم يُجرَّب تشغيل الفصول.
